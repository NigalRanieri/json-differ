json-differ

A configurable structural JSON comparison and diffing library for Java 8+.

GitHub Maven Central API Documentation

Quick Start

ComparisonResult result =
    JsonCompare.compare(expected, actual);

if (!result.isEqual()) {
    System.out.println(result);
}

Installation

Maven

<dependency>
    <groupId>io.github.nigalranieri</groupId>
    <artifactId>json-differ</artifactId>
    <version>0.1.0</version>
</dependency>

Gradle

implementation 'io.github.nigalranieri:json-differ:0.1.0'

Features

  • Structural JSON comparison
  • Detailed differences with JSON paths
  • Ignored paths with wildcard support
  • Optional unordered array comparison
  • Numeric tolerance
  • Reusable configured comparators
  • Java 8 compatible
