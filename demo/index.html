YAML configuration is optional.

Leave this box empty for strict comparison.

  • Ignored paths — ignore values or subtrees.
  • Array order — ignore order globally or at selected paths.
  • Null vs missing — treat them as equal globally or at selected paths.
  • Numeric tolerance — set global or path-specific tolerances.
  • Ignore case — compare string values case-insensitively globally or by path.
  • Output format — use traversal or grouped.
  • Max cell width — control wrapping in formatted results.

Path wildcards:

  • * — any property at one level
  • [*] — any array index
  • ** — recursive matching

Invalid YAML, unknown settings, invalid paths, and invalid values are rejected.
